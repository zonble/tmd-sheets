# 楊金土手抄《唱歌帖》原編第 2 冊（封面標記 `2` / `II`）

* **返回總目錄**：[《楊金土手抄唱歌帖》十冊總目錄 (`../index.md`)](../index.md) ｜ [專題考證 (`../research_notes.md`)](../research_notes.md)
* **封面標記與署名**：封面頂端手寫標註 **`2`**，左上角裝飾五線譜高音譜號左側鉛筆署名 **「楊金土」**、拍號右側標註羅馬數字 **`II`**（對應 [`P115.jpg`](../../shokacho_2020.006.0843/P115.jpg) 總目錄之 `2.`）
* **對應臺史博館藏與掃描範圍**：`2020.006.0843` 第 3 冊（掃描頁碼 [`P065.jpg`](../../shokacho_2020.006.0843/P065.jpg) – [`P112.jpg`](../../shokacho_2020.006.0843/P112.jpg)，共 48 頁）
* **原冊題名／板式**：《唱歌帖》（封底印有 `BK. NO. 1` 地球大象商標）
* **抄錄年代**：大正 12–14 年（1923–1925）
* **主要內容與抄錄來源**：前半（`P069`–`P079`）手抄自《大正幼年唱歌》、《教育幼稚唱歌集》、《愛吟抄》；中段（`P080`–`P081`）收錄抄自「邱氏」之〈近眼のしくじり〉及**臺灣傳統藝旦／北管小曲五線譜採譜〈嘆烟花〉（[`P081.jpg`](../../shokacho_2020.006.0843/P081.jpg)）**；後半（`P082`–`P109`）為五線譜貼頁與手抄譜（含〈小楠公〉、〈曉景〉、〈埴生の宿〉、〈樂しき我家〉、〈美しき天然〉等）。
* **收錄樂曲數**：共 **35 首**（70 個 `.tmd` 樂譜檔，含每首原譜版與 `_piano.tmd` 鋼琴伴奏版）
